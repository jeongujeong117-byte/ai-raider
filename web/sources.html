1. 대상 범위 → 추출 도구 → 분류 도구

기본 최근 3개월 · 날짜 미확인 자료는 버리지 않고 표시합니다. 실제 조회 범위는 제공 목록·건수·페이지 상한에 제한됩니다. RSS는 과거 전체 아카이브가 아닙니다. 허깅페이스는 파일 목록·카드·설정을 받으며 모델 가중치와 전체 데이터셋은 자동 다운로드하지 않습니다.

로그인·브라우저 준비

브라우저 보완은 설치된 Microsoft Edge와 별도 수집 프로필을 사용합니다. 로그인 필요 시 터미널에서 uv run --extra browser python raider.py source-browser-login 주소를 실행하고 직접 인증하세요. 수집 옵션을 켜면 공개 요청 실패 후 그 프로필로 다시 읽습니다. CAPTCHA·유료벽·접근 권한을 자동 우회하지 않습니다.

유튜브 로그인은 본인 세션의 Netscape 형식 쿠키 파일을 .private/youtube.cookies.txt에 둡니다. 쿠키를 채팅에 보내지 마세요. yt-dlp가 세션을 재사용하지만 로그인만으로 모든 영상 수집을 보장하지는 않습니다.

2. 진행 상태

정보원별로 독립 실행합니다. 중단한 대상은 다시 읽고 게시글 ID로 저장 중복을 막습니다. 저장 완료 후 공통 OCR·전사 대기열에서 처리하며 화면을 닫아도 서버가 켜져 있으면 계속합니다.

3. 원본과 추출 결과 · 게시글별 묶음

정보원 전체 JSON 저장

분류는 키워드 초안이며 AI 요약이 아닙니다. 본문·첨부·제공 자막·OCR·전사는 같은 원문 키에 연결됩니다.
