GitHub 에이전트

누적 스타로 발견하고, 파일과 문서를 저장하고, 관측 기록으로 관심 변화를 비교합니다.

1. 수집 범위

기존 인기 모드에는 저장소 생성일 제한이 없습니다. 기준일은 릴리스에만 적용합니다. 최근 생성 모드는 그 날짜 이후 생성한 저장소를 찾으며 ‘최근 스타 급증’과는 다릅니다. 재관측 모드는 아래 검색식·직접 지정·스타 하한 대신 이미 수집한 모든 저장소를 대상으로 합니다.

직접 지정한 저장소는 스타·날짜 하한과 관계없이 추가합니다. 특정 저장소만 받으려면 검색식을 지우세요.

공개 저장소만 조회합니다. 파일은 기본 브랜치의 특정 커밋 스냅샷입니다. 전체 커밋 이력·다른 브랜치·별도 릴리스 바이너리·서브모듈 내용·LFS 원본은 포함을 보장하지 않습니다. ZIP은 실행하거나 자동 설치하지 않습니다.

접근 토큰 설정과 검색 제한

토큰 없이도 공개 자료를 조회할 수 있지만 요청 한도가 낮습니다. 선택적으로 이 프로그램을 실행하는 터미널에 GITHUB_TOKEN 또는 GH_TOKEN 환경 변수를 설정하고 서버를 재시작하세요. 토큰은 이 화면·채팅에 붙이지 않습니다.

검색식당 최대 1,000건, 한 작업에 검색식 최대 20개입니다. 스타 하한과 여러 검색식으로 탐색 범위를 나누세요. 검색 결과는 GitHub 전체 목록이 아니며 요청 제한이 발생하면 중단 후 이어받습니다.
