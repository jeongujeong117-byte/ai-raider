AI Raider

수집·추출 v0.3

계정을 고르고 기간을 정해 게시물을 모으세요. 자료는 이 컴퓨터에 저장됩니다. GitHub 전담 에이전트 → 유튜브·뉴스·허깅페이스·갤러리 →

1. 로그인 준비

처음 연결하는 방법

프로젝트 터미널에서 다음 명령을 실행하세요. 아이디·비밀번호·쿠키는 이 화면이나 채팅에 입력하지 않습니다.

Instagram: uv run python raider.py login-instagram

X: uv run twscrape --db .private/x-accounts.db add_cookie my_account

세션 파일이 있다는 표시가 로그인 유효성 검증을 뜻하지는 않습니다. 자세한 설치·세션 설정은 README를 참고하세요.

2. 계정·분류 관리

플랫폼별로 분류를 따로 관리합니다. 기존 계정의 초기 분류는 계정 소개를 바탕으로 정했으며 아래에서 수정할 수 있습니다.

등록 계정별 분류 수정

공백·줄바꿈·쉼표 또는 연속된 @로 구분할 수 있습니다. 같은 플랫폼의 프로필 링크도 지원합니다. 형식 확인 후 실제 계정 존재 여부는 수집 시 확인합니다.

3. 수집 범위

한국시간 기준 · 종료일 포함. 기본값은 실행하는 날 기준 3개월 전입니다.

분야·개인 취향·좋아요 수로 게시물을 제외하지 않습니다. 파일 저장을 선택하면 이미지·영상·썸네일을 내려받습니다(파일당 최대 512MB). 저장 후 종류를 판별해 이미지 OCR·영상 음성 전사·화면 OCR을 자동 대기열로 보냅니다.

4. 진행 현황

조회 종료는 전체 역사 자료의 완전성 인증이 아닙니다. X는 날짜별 검색, Instagram은 프로필 전체 목록을 순회합니다. 미완료 구간은 다시 조회하고 이미 저장한 글은 합칩니다. 중지 요청은 현재 네트워크 응답 후 반영될 수 있습니다.

5. 자동 추출

본문 → 그대로 보존 / 이미지 → 한국어·영어 OCR / 영상 → 음성 전사 + 화면 OCR. 모두 원래 게시글 하나에 묶입니다. 영상 화면은 5초 간격, 최대 300장 표본이며 순간적으로 나오는 글자는 놓칠 수 있습니다. 이미지의 의미 설명·AI 요약은 포함하지 않습니다.

원본 파일이 없는 첨부는 다운로드 후 다시 처리해야 합니다. 모델 준비: uv sync --extra processing → uv run --extra processing python raider.py prepare-processing. 최초 모델 준비 후 원본 파일은 외부 AI 서비스로 보내지 않습니다.
