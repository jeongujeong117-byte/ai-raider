# 정보원별 구현 작업 단위와 검증 기록

2026-11-10

공통 목표: 정보원별로 대상 범위 → 추출 도구 → 분류 도구를 구현하고 원문 하나 아래 본문/첨부/파생 데이터를 묶는다. 한 프롬프트에 요구가 하나여야 한다는 절대 규칙은 없으므로, 관련 요구와 제약은 유지하고 작업의 완료 단위를 나눈다. 새 AI 채팅을 자동 생성하거나 외부 모델에게 임의 지시를 보내지는 않았다.

## 단위 1 · GitHub

요청: GitHub 전담 에이전트를 누적 스타 탐색·지정 저장소·커밋 ZIP·SKILL.md·두 분야 분류·재관측까지 완성하고 단위/통합/실제 공개 조회로 검증하라.

상태: v0.4 구현 및 실제 ZIP/검색 조회 검증 완료. 전체 GitHub 완전 수집은 범위 밖.

## 단위 2 · YouTube

요청: yt-dlp를 사용해 채널/재생목록/영상 URL에서 기간·건수 범위 내 정보·제공 자막·선택 파일을 수집하고 공통 OCR/전사 대기열에 연결하라. 접근 실패를 숨기지 말고 원문을 보존하라.

상태: 구현·모의 파일/자막 테스트 완료. 실제 영상 정보 성공. 공식 권장 yt-dlp[default]와 Node 런타임 보완 후 65초 영상 약 2.8MB 다운로드 성공. 제공 자막 HTTP 오류는 남아 있으며 영상 파일의 로컬 전사/화면 OCR 경로로 보완한다. 결과는 data/verification-other에 기록한다.

## 단위 3 · 뉴스

요청: feedparser/Trafilatura를 사용해 RSS와 지정 기사에서 본문·날짜·이미지를 수집하고 기사별 묶음을 유지하라. RSS의 과거 보관 한계를 표시하라.

상태: 구현·단위 검사 및 실제 기사 본문·이미지 다운로드 성공.

## 단위 4 · Hugging Face

요청: 공식 HfApi로 모델/데이터셋/Spaces의 목록·카드·파일 목록·설정을 수집하라. 가중치 자동 다운로드·코드 실행은 하지 말고 범위를 기록하라.

상태: 구현·단위 검사 및 실제 모델 카드·파일 16개 목록 확인.

## 단위 5 · AI 활용 갤러리

요청: ai_utilize 공개 목록을 페이지 순회해 본문·추천·조회수·첨부를 수집하고 기간·상한·오류를 기록하라. 필요하면 선택형 수집용 브라우저 프로필 경로를 제공하라.

상태: 구현·단위 검사 및 실제 게시글 1건 조회 성공. 로그인된 Edge 경로는 사용자 인증 후 별도 검증 필요.

## 단위 6 · 공통 연결

요청: 네 에이전트를 독립 실행·중지·재개하고 게시글 ID 중복 방지, 공통 OCR/전사 연결, 화면 조회·JSON 내보내기를 검증하라.

상태: 단위 50개 통과. HTTP 통합·JS 문법 검사 통과. 소셜·GitHub의 기존 테스트 포함. 별도 예약 개발 작업은 만들지 않았다.

최종 실검증: 뉴스 이미지 OCR과 실제 YouTube 영상의 Whisper 전사·화면 OCR 완료를 확인했다. 예약 개발 작업 없이 이번 실행에서 네 정보원 도구 구현과 검증을 끝냈다. 제공 자막 오류, 로그인된 Edge 수집 실검증, 각 사이트의 전체 과거 자료 확보는 미해결 제약으로 구분한다.
