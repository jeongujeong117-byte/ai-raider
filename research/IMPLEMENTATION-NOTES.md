# 수집기 구현·검증 기록

2026-11-09 / AI Raider v0.1

## 선택한 구성

Instagram은 Instaloader 4.16, X는 twscrape 0.21.0을 로컬 Python 애플리케이션에서 호출한다. 검증된 설치 조합은 uv.lock에 기록했다. 계정 62개는 기존 config/sources.json을 그대로 읽는다. 수집과 AI 후처리를 분리하며 유료 AI 키 없이 시작한다.

참조: [Instaloader Python API](https://instaloader.github.io/as-module.html), [Instagram 게시물 구조](https://instaloader.github.io/module/structures.html), [twscrape](https://github.com/vladkens/twscrape), [상용 관리형 대안 Apify](https://apify.com/apify/instagram-scraper).

## 이번에 확인한 것

- 실제 패키지 설치와 API·CLI 시그니처 확인.
- 테스트 8개 통과: 달력 월·윤년, 한국시간 경계, 계정 중복, X 날짜 구간, DB upsert·결측 반응, 실패 후 재개, 프로세스 재시작, 오래된 고정 게시물 이후의 Instagram 게시물 수집.
- 독립 임시 DB의 HTTP 검사 통과: 화면, 계정 62개, 게시물 조회, CSV 내보내기, CSRF 거부, 빈 계정 선택·없는 작업 재개 거부.
- JavaScript 문법 검사 통과.
- 브라우저에서 한국어 화면, 2026-08-09~2026-11-09 기본 날짜, 계정 62개, 로그인 필요 상태, 빈 게시물 목록 표시 확인.

## 남아 있는 실계정 검증

사용자 Instagram·X 세션이 없어 로그인 후 네트워크 수집은 실행하지 않았다. 프로필 접근 제한, 검색 누락, 레이트리밋, 비공개 반응 등 실제 플랫폼 응답은 연결 후 검증해야 한다. 조회가 끝났어도 과거 자료 전체가 완전하다고 표시하지 않는다.

Instagram은 프로필 전체 목록을 재순회하므로 재개 시 미완료 계정을 다시 읽는다. X는 미완료 UTC 날짜 구간부터 다시 읽는다. 두 경로 모두 저장된 게시물은 고유 ID로 합친다. 페이지 커서를 영구 저장하는 기능은 없다.

이미지·영상 참조와 게시물 본문을 수집한다. 카드뉴스 속 글, 영상 대사, 댓글 본문은 아직 추출하지 않는다. 이를 읽으려면 후속 단계에서 OCR·음성 전사 또는 이미지 이해 모델을 연결한다. AI 관련성·한국어 분류와 사건 단위 중복 묶기도 후속 단계다.


## v0.2 변경·검증 (2026-11-09)

- 플랫폼별 분류, 사용자 분류 추가, 계정별 분류 변경과 JSON 영구 저장.
- 여러 @계정 일괄 미리보기·등록. 연속 @, 공백, 줄바꿈, 쉼표, 프로필 링크 지원. 플랫폼별 대소문자 무시 중복 검사, 잘못된 항목 포함 시 일괄 거부.
- 파일 저장 옵션: Instagram 캐러셀·영상, X 사진·MP4·애니메이션·썸네일. 파일당 512MB, CDN 주소·리다이렉트 검증, 전송 중단·미완성 파일 정리. 본문 저장 후 파일 저장, 실패 기록·재시도.
- 기존 SQLite 작업의 파일 저장 옵션은 마이그레이션으로 꺼짐 유지. 신규 화면 작업은 기본 켜짐.
- 단위 검사 16개 통과, 독립 임시 계정 설정·DB HTTP 통합 검사 통과, JavaScript 문법 검사 통과.
- 실제 브라우저에서 Instagram 연속 @ 입력의 기존 2계정·잘못된 1항목 표시, X 전환 시 별도 분류 및 신규/기존 계정 미리보기, X만 선택 시 30개 대상으로 축소 확인. 테스트용 계정은 실제 설정에 등록하지 않았다.
- 사용자 로그인 세션이 없어 실제 소셜 플랫폼 파일 전송은 아직 미검증. 테스트용 응답으로 파일 저장·캐시·잘못된 MIME·크기 제한·전송 누락·중단을 검증했다.
- OCR·음성 전사는 아직 실행하지 않는다. Tesseract/faster-whisper는 유료 생성형 AI API 없이 별도 적용 가능하나, 특히 전사는 신경망 AI 모델을 사용한다. 코랩은 실행 환경이다.


## v0.3 자동 추출·게시글 묶음 (2026-11-09)

Tesseract 5.5.3/tesserocr 2.12.0 및 tessdata_fast kor+eng, faster-whisper 1.2.1 small CPU int8, PyAV 17.1.0을 설치하고 공개 모델을 로컬 data/models에 준비했다. 영상은 직접 디코딩하므로 별도 FFmpeg 실행 파일 없이 동작한다. 본문·첨부별 OCR·시간별 음성 전사·화면 OCR을 platform/post_id에 연결했다. SQLite 별도 처리 대기열과 입력 지문으로 재수집 보존·중복 방지·재시작 복구를 구현했다. 화면 표본은 5초 간격 최대 300장이고 의미 분석 모델은 사용하지 않는다.

24개 단위 검사와 HTTP 추출/묶음 export 통합 검사 통과. 실제 인식 모델로 테스트 이미지의 영문 및 한국어 인식, 12초 영상의 0/5/10초 OCR, 무음 영상 판정, Windows 합성 음성의 영문 전사를 확인했다. OCR에 일부 오독이 있어 추출문이 원문과 동일하다고 보장하지 않으며 원본을 보존한다. 실제 SNS에서 받아온 파일은 로그인 미연결로 아직 검증하지 않았다.
