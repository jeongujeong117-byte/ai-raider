# T-003 · 평가 정답 샘플과 블랙박스 틀

## 역할 및 모델
S2 Antigravity, 사용자 정책대로 자체 설정 기본 모델/effort. handoff/AGENTS.md와 ROLES 보안 준수. 제품 수정 없이 입출력으로 평가한다. 모든 연락은 Orca orchestration으로 S0를 거친다.

## 목표
외부 계정 자료를 읽지 않고 합성 게시물 정답 데이터와 재실행 가능한 fixture 검증 틀을 만든다.

## 수정 허용 파일
- `tests/blackbox/__init__.py`
- `tests/blackbox/fixtures/gold_samples.json`
- `tests/blackbox/test_gold_samples.py`
- `tests/blackbox/README.md`
- `handoff/reviews/T-003-qa.md`

그 외 전부 수정 금지. 기존 test_t000_structure.py·제품 코드·기존 테스트·BOARD/DECISIONS 금지. T-001/T-002와 공유 파일 없음.

## 인터페이스 및 정답 계약
- UTF-8 JSON: {'schema_version':1,'samples':[...]} 최소 12개 사례. 각 sample은 고유 id, description, input(기존 posts dict 형태), expected(검증 가능한 기대값), tags, provenance='synthetic'. 텍스트·URL 모두 합성이며 example.com 등 예약 예시 URL만 사용.
- 7개 플랫폼 instagram/x/youtube/news/gallery/huggingface/github 모두 포함. likes=None과 0 구별, 빈 본문+미디어, OCR/전사, 2026-08-09 00:00 KST 직전/정각/직후, 동일 (platform,post_id) 재수집, mock 레이트리밋, 대형 유니코드 입력을 다룬다.
- expected는 preserve_null_metrics, stored_text, dedup_key, in_window 등 구체값으로 표현하고 현재 Store와 raider.window 등 공개 인터페이스로 검증한다. 고유 sample id와 dedup_key를 구분한다.
- 미래 분석용 정답은 expected.analysis에 category/evidence_terms/is_pure_noise 같은 수작업 기준안으로 명시하고 현재 미구현 하네스 통과를 주장하지 않는다. 순수 잡담에서 기술을 지어내지 않고, 잡담 속 기술 쓰임새·신개념·실습 아이디어는 원문 근거에 연결. fixture 내부 known_concepts를 명시해 사용자 지식을 추정하지 않는다.
- 대용량은 JSON에 반복 본문 수 MB를 넣지 말고 repeat_count/base_text를 테스트에서 확장하여 길이/규모 명시.
- README에 사례별 목적/기대값 근거, 실행 명령, 현재 자동 검증 범위와 미래 하네스 검증 잔여를 설명. T-000 블랙박스 실행법 포함.

## 완료 증거
- `uv run python -m unittest discover -s tests -v` 및 `uv run python -m unittest discover -s tests/blackbox -v` 모두 exit 0. __init__ 추가로 상위 discover에 blackbox가 포함되므로 실제 총 수를 보고.
- 새 tests는 schema/고유 id/7개 플랫폼/기대값 근거, 임시 Store의 None·빈 본문·재저장·대용량, 고정 now KST 경계, fake collector 레이트리밋 오류 마스킹을 검증. 분석기를 새로 구현하거나 미구현 분석을 skip해 성공처럼 보이지 않는다.
- 실제 SNS/사용자 data/.private/세션 읽기 금지. 합성·임시 데이터만 사용. `git diff --check` 통과.
- handoff/reviews/T-003-qa.md에 PASS/FAIL, 명령·종료 코드·테스트 수, 샘플별 의도, 미검증 및 미래 분석 기준안의 한계. FAIL은 재현/기대/실제 포함.

## 보고
허용 파일만 커밋 후 worker_done으로 브랜치·커밋·보고서·증거 반환. 미완료 검증은 PASS로 보고 금지. 자체 산출물 PASS는 S0 수락 검토 전 자동 병합 허가가 아니다.
