# T-001 / T-003 · 병합 후 학습 문서

## 역할 및 모델
S3 튜터. 모델 `claude-sonnet-5-5`, effort `low`. 비전공자 사용자를 가르치며 코드와 기존 문서는 읽기만 한다. 파일은 지정 docs/learn/만 작성. 다른 AI 직접 연락·BOARD/DECISIONS 수정 금지.

## 목표와 근거
develop에 수락·병합된 T-001 상태 감시 기반과 T-003 합성 gold dataset을 한국어로 설명한다. 해당 handoff/specs, reports(T-001), reviews, 코드와 테스트를 근거로 한다. T-001 개발 최종 140fcdf, QA 0f0b8cb(원본 7c51734 FAIL 이력 보존). T-003 최종 ff69a03, 15개 합성 사례·신규 12개 테스트. S0 병합 후 전체 테스트 98개, blackbox 30개 exit 0.

## 내용 및 제약
각 문서에 어떤 문제를 푸는지, 왜 이 구조인지, 실제 사용한 라이브러리/stdlib 역할과 선택의 장단점, 가능한 대안, 실제 파일·함수 경로와 짧은 예를 설명한다. 각 문서 마지막에 서술형 문제 3개와 모범 답안을 붙인다. 모르는 건 '코드에서 확인 안 됨'.

T-001은 네 상태/중단 가능한 제한 재시도/주입 fallback/원자 JSON 상태 기록, source별 전용 파일 전제를 설명한다. 실제 수집기·대시보드·Edge 연결은 후속 통합이며 자동 우회가 이미 동작한다고 쓰지 않는다. 최초 PASS를 S0가 미수락한 이유(잘못된 기대값)와 1차 반려 수정/재검증을 설명한다.

T-003은 sample id와 dedup_key, None/0 구분, KST 경계, 예약 예시 호스트, 합성 근거/known_concepts, 실제 저장소 검증과 미래 분석 정답의 일관성 검증 차이를 설명한다. 모델의 분류/환각 성능을 검증했다고 쓰지 않는다. gold 기준안은 S0 승인으로 개정 가능하며 사용자 지식 사전 자체가 아니다. 테스트 수/파일 수는 해당 수락 시점 기준임을 명시한다.

## 완료 증거 및 반환
사실·경로·클래스·테스트 수를 코드/보고서와 대조하고 git diff --check 통과. 문서만 쓰므로 제품 테스트 재실행 불필요. 허용 두 파일만 커밋 후 worker_done으로 최종 커밋·문서 경로·미검증 반환. 실제 DB/.private/세션/쿠키/토큰 읽기·외부 수집·push 금지.
