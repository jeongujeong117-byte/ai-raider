## 인터페이스와 필수 검증
- `PostReader(db_path)` : 존재하지 않는 파일 FileNotFoundError, 파일 자동 생성 금지. Store 생성자 호출 금지. mode=ro와 query_only. 요청마다 연결 정리.
- `list_posts(platform='',handle='',offset=0,limit=100)` : {'total':int,'items':list}, total은 페이지 전 수, 정렬 posted_at DESC/platform ASC/post_id DESC. limit int 1~500, offset int >=0, bool/잘못된 타입/범위 거부. 필터는 문자열. SQL 인젝션은 리터럴로 처리. 페이지 경계·빈 데이터·안정 정렬을 확인한다.
- `get_post(platform,post_id)` : 둘 다 비어 있지 않은 문자열, 해당 글 dict 또는 None. 플랫폼 다른 동일 ID 격리.
- `list_unanalyzed` : post_analyses가 없으면 전체. 있으면 (platform,post_id) 일치 글 제외. processing은 OCR이므로 분석 완료로 간주 금지. 필수 식별 열 누락은 명시적 안전 오류. NULL·중복 분석 이력·다른 플랫폼 ID·필터와 페이지 조합도 확인한다.
- JSON metrics/media/raw 파싱, likes=None과 0 구별, 빈 본문·300k 이상 유니코드 무절삭, 손상 JSON/손상 또는 테이블 없는 DB는 명시적 오류. 고정 메시지이며 원시 SQL/DB 절대경로/가짜 비밀을 MCP 응답·로그에 노출하면 안 된다.
- `create_server(db_path)`의 도구는 정확히 list_posts/get_post/list_unanalyzed. annotations readOnlyHint true/destructiveHint false. stdio 클라이언트로 initialize/list_tools/각 call_tool 정상·null·오류·불법 인자를 실제 수행한다. 특히 direct API와 MCP 경계에서 bool/문자열 수치가 SDK에 의해 강제 변환되어 검증을 우회하는지도 대조하고 spec 위반 여부를 보고한다.
- import 부작용 없음, --help, 없는 DB 종료/파일 미생성, stdout JSON-RPC 외 출력 없음. 오류 stderr도 가짜 비밀/절대 DB 경로 미노출 확인.
- 요청 전후 hash/mtime/테이블 비교로 데이터/스키마 불변. DELETE 시도 차단. rollback journal 및 임시 WAL DB도 시험하고 -wal/-shm 생성·변경 여부를 별도 기록한다. immutable=1로 강제해 최신 WAL 데이터를 누락시키는 해결은 하지 않는다. WAL 최신 커밋을 정확히 조회하는지도 검증한다. 사이드카의 관찰 사실과 원문/스키마 변경을 구분해 보고한다.
- 부작용 없는 stdio shutdown과 연결 정리 확인. 화면 없는 로컬 MCP이므로 브라우저 불필요.

## 완료 증거 및 판정
`uv sync --extra processing --extra mcp`, `uv run --extra processing --extra mcp python -m unittest discover -s tests -v`(개발 67개), `uv run --extra mcp python -m unittest discover -s tests/blackbox -v`(기존 7+신규), CLI help, `git diff --check`. 실제 명령·종료 코드·테스트 수를 보고한다. mcp extra 없이 서버 전용 신규 테스트의 명시적 skip은 optional 환경 특성으로 구분하고, 필수 MCP 검증은 extra 설치 후 skip 없이 수행한다. 기존 테스트 skip/완화 금지.

FAIL이면 최소 입력/재현 명령/기대값/실제값을 적고 고치는 방법은 제안만 한다. 필수 증거 미확보는 PASS로 쓰지 않는다. handoff/reviews/T-002-qa.md에 판정, 검증 커밋, 필수 항목별 결과, WAL 관찰, 미검증을 기록하고 허용 QA 파일만 커밋. worker_done으로 QA 브랜치·커밋·보고서·판정을 S0에 반환한다.
