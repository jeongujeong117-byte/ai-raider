# T-001 · 공통 수집기 상태 감시 기반

## 역할 및 모델
S1 구현 담당. 모델 `claude-sonnet-5-5`, effort `medium`. handoff/AGENTS.md와 이 spec을 따른다. 허용 파일 외 수정 금지. 설계 변경은 먼저 Orca ask로 S0에 질문한다. 다른 AI 직접 연락 금지.

## 인터페이스
- `HealthState(str, Enum)` 값은 정확히 HEALTHY, RATE_LIMITED, SESSION_EXPIRED, BLOCKED_FALLBACK.
- `RateLimited(retry_after: float=60)`, `SessionExpired`, `Blocked`, `SupervisorStopped` 예외 공개. retry_after는 유한한 0 이상 실수만 허용하고 잘못된 값은 ValueError.
- `Supervisor(source: str, state_path=None, *, clock=None)`: source는 비어 있지 않은 식별자. state_path는 선택적인 해당 source 전용 JSON 파일. 없으면 메모리만 사용. 초기 HEALTHY. clock은 epoch seconds callable(기본 time.time). import/생성만으로 스레드·수집·브라우저 시작 금지.
- `snapshot()` -> JSON 직렬화 dict: source, state(문자열), updated_at(epoch seconds), retry_at(없으면 None), reason(고정된 비밀 없는 코드). 원시 예외 메시지·쿠키·토큰 저장/출력 금지.
- `run(operation, *, stop=None, fallback=None, max_retries=3)` : operation() 결과 반환. stop은 threading.Event 호환 객체, 없으면 새 Event. 대기는 stop.wait(seconds)로 중단 가능하게 한다. max_retries는 bool 제외 0 이상 정수(추가 재시도 횟수).
- 정상 operation 성공은 HEALTHY/retry_at=None. RateLimited는 RATE_LIMITED/retry_at=clock()+retry_after로 기록하고 대기 후 한정 재시도. 한도 초과 시 해당 예외를 올리고 RATE_LIMITED 유지. 중단은 SupervisorStopped를 올리고 추가 operation 호출 금지.
- SessionExpired는 SESSION_EXPIRED 기록 후 즉시 다시 올리고 재시도/우회 금지.
- Blocked는 BLOCKED_FALLBACK 기록. fallback이 있으면 한 번 fallback() 실행 후 결과 반환. 성공 시에도 BLOCKED_FALLBACK 유지(우회 모드 표시). 없거나 실패하면 예외를 올리고 무한 루프 금지. fallback은 향후 Edge 연결 주입 지점이며 실제 브라우저를 띄우지 않는다. fallback의 RateLimited/SessionExpired는 대응 상태로 기록하되 추가 재시도는 하지 않는다.
- 일반 예외는 재시도하지 않고 올리며 reason='operation_error' 등 고정 코드만 기록. 다섯 번째 상태 금지.
- state_path 지정 시 변경마다 UTF-8 JSON 원자적 저장 및 같은 source 상태 복원. source 불일치·깨진 파일은 명시적 ValueError(내용 출력 금지)로 처리하고 덮어쓰지 않는다. 임시 파일 정리, 저장 실패를 숨기지 않는다. source별 전용 파일을 사용하며 한 인스턴스 제한이 다른 source를 막으면 안 된다.

### 1차 검토 명확화
중단 의미는 fallback에도 적용된다. operation이 stop을 설정하고 Blocked를 올리면 fallback 직전에 다시 확인하여 SupervisorStopped를 올리고 fallback을 호출하지 않는다. 복원 reason은 init/ok/rate_limited/session_expired/blocked/fallback_used/fallback_error/fallback_rate_limited/fallback_session_expired/operation_error의 고정 코드만 허용한다. 임의 문자열을 복원 후 실행으로 덮어쓰는 것은 계약 충족이 아니다. 미등록 reason은 안전 ValueError로 거부하고 원본 파일을 보존한다.

## 완료 증거
변경 전/후 `uv run python -m unittest discover -s tests -v` 및 `uv run python -m unittest discover -s tests/blackbox -v` 모두 exit 0. 새 테스트로 네 상태, 정상 복구, 재시도 한도 0/3, stop 즉시/대기 중, fallback 1회, 세션 만료 무재시도, source 격리, 저장/복원/오염, 비밀 미기록 검증. mock clock/Event로 실제 대기/네트워크 없이 실행. `git diff --check` exit 0.
