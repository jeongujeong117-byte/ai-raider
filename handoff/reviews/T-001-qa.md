## 최초 커밋 `7c51734` 결함 재현 내역 (보존 증거)

### 1. Stop 설정 후 Blocked 발생 시 Fallback 무단 호출 (`test_06`)
- **재현 명령**:
  ```sh
  uv run python -m unittest tests.blackbox.test_t001_supervisor.BlackboxSupervisorTests.test_06_stop_semantics_and_blocked_fallback_contrast -v
  ```
- **최소 입력**:
  ```python
  stop = threading.Event()
  def op():
      stop.set()
      raise Blocked()
  def fallback():
      return "ran_after_stop"
  sup.run(op, stop=stop, fallback=fallback)
  ```
- **기대값**: `SupervisorStopped` 예외 즉시 발생, fallback 호출 0회 (`fallback_invocations == []`).
- **`7c51734` 실제값**: `SupervisorStopped` 미발생, fallback이 1회 호출되어 `"ran_after_stop"` 반환. (계약 위반)

### 2. 상태 파일 복원 시 비인가 임의 `reason` 수용 (`test_10`)
- **재현 명령**:
  ```sh
  uv run python -m unittest tests.blackbox.test_t001_supervisor.BlackboxSupervisorTests.test_10_persistence_roundtrip_corruption_attacks_and_source_isolation -v
  ```
- **최소 입력**:
  ```python
  state_path.write_text(json.dumps({
      "source": "source_a",
      "state": "HEALTHY",
      "updated_at": 100.0,
      "retry_at": None,
      "reason": "SYNTHETIC_UNAPPROVED_REASON"
  }), encoding="utf-8")
  Supervisor("source_a", state_path)
  ```
- **기대값**: `ValueError`("invalid supervisor state file") 예외 발생 및 디스크 원본 파일 불변.
- **`7c51734` 실제값**: 예외 없이 정상 로드되어 `s.snapshot()["reason"] == "SYNTHETIC_UNAPPROVED_REASON"` 노출. (계약 위반)

### 1. `test_06` 중단(Stop) 계약 및 Blocked fallback 검증 (PASS)

  - fallback 호출 횟수: **0회** (`fallback_invocations == []`)

### 2. `test_10` 상태 파일 복원 시 고정 reason 화이트리스트 검증 (PASS)
- S1이 `agents/base_supervisor.py`에 고정된 10종 reason 집합(`_REASONS = frozenset({"init", "ok", "rate_limited", "session_expired", "blocked", "fallback_used", "fallback_error", "fallback_rate_limited", "fallback_session_expired", "operation_error"})`)을 정의하고, `_load()`에서 `if data["reason"] not in _REASONS: raise ValueError`를 적용함.

  - 명시적 **`ValueError`**("invalid supervisor state file") 발생 확인.
