```python
_VALID_REASONS = frozenset({
    "init",
    "ok",
    "rate_limited",
    "session_expired",
    "blocked",
    "fallback_used",
    "fallback_error",
    "fallback_rate_limited",
    "fallback_session_expired",

```
`_load()` 메서드 내 검증 조건:
```python
if data["reason"] not in _VALID_REASONS:
```

```python
except Blocked:
```
