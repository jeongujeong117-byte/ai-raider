## 현재 위치와 운영 제약

Phase 1은 구조/감시 기반만 완료, 통합 미완료. Phase 2는 스키마 기반 완료, 사용자 사전 갱신/평가 기반 준비. Phase 3 미착수. Phase 4는 조회 MCP/블랙박스 기반만 완료. 서비스 1의 실제 범위 완료도 측정 증거 없이 단정하지 않는다. 항목별 근거를 S4가 확인하며 전체 완료율은 작업 크기가 달라 단순 계산하지 않는다.

X 3개월치는 사용자 측에 이미 있어 재크롤링하지 않는다. Instagram feedback_required 차단으로 재수집/재연결하지 않는다. 갤러리 소량 공개 수집도 별도 spec/사용자 승인 전 실행하지 않는다. Drive 3.9GB DB는 미다운로드로 사용자 제공 사실이며 AI가 확인한 것으로 쓰지 않는다. 사용자 원본 DB/미디어/.private 접근 없이 지정 샘플만 후속 T-008에서 활용한다.

T-004 합성 사전의 concepts 12개는 실제 사용자 지식이 아니다. 사용자 응답으로 실제 기지식은 환각/프롬프트 엔지니어링/컨텍스트 윈도우/RAG/임베딩 5개로 확정됐다. 파인튜닝/MCP/LoRA/양자화/에이전트 하네스 및 사전 미등재 생소한 개념은 원문 근거가 있을 때 신개념 후보이며, 갤러리 [신개념 발견] 격상 시 쉬운 한국어 뜻풀이를 붙인다. 사용자 수준은 기초 완료・중급 초입이다. 현재 QA는 중단/재시작하지 않고 다음 갱신 T-006에서 config/provenance/테스트를 반영한다. 전역 UI/분석에서 12개를 사용자의 기지식으로 적용하지 않는다.
